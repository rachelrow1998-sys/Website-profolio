# profile.html 用的两张照片

这一屏只有两张图，**两张必须是同一个机位、同一个姿势拍的**——
一张不戴头盔（底层），一张戴头盔（光标圆圈里露出来的那层）。
机位一致，圆形光标扫过去才会像「在同一张照片里翻另一层」，
错位了就只是两张图在硬切。

| 文件名 | 是哪一张 | 说明 |
|---|---|---|
| `portrait.jpg` | 图一，不戴头盔 | 铺满整屏的底图 |
| `helmet.jpg`   | 图二，戴头盔   | 只在圆形光标里出现 |

## 怎么换成你自己的照片

把两张图按上面的文件名放进这个文件夹就行，**不用改任何代码**：

```
assets/img/profile/portrait.jpg
assets/img/profile/helmet.jpg
```

在这之前，页面会自动退回同名的 `*.placeholder.svg` 占位图
（`profile.html` 里的 `onerror` 负责这件事），所以现在打开也不会开天窗。

## 拍摄 / 导出建议

- **竖构图**，2:3 左右（例如 1400 × 2100），白色或极浅的背景。
- 两张的**人物大小、位置、光线要一模一样**——最好是同一次拍摄里连拍的。
- 导出 JPG，质量 80 左右，单张控制在 300–500 KB；再大首屏会等。
- 人脸别放在正中间：页面按 `object-position: 50% 32%` 裁切，
  人脸大概落在上三分之一。要调的话改 `assets/css/profile.css` 里的
  `--focus-x` / `--focus-y`（JS 画布会自动跟着这两个值走，不用改两处）。
